# JanAwaz

Independent citizen grievance assistance platform. MVP scope: Bihar electricity complaints (SBPDCL, NBPDCL).

Modular monolith: `backend/` (FastAPI) + `frontend/` (Next.js). See `docs/` for context and the phased plan.

## Status

| Phase | Scope | State |
| ----- | ----- | ----- |
| 1 | Backend foundation: database models, Alembic migrations, service layer, tests | Done |

Phase details live in `docs/phases/` (see `docs/phases/phase-1-backend.md`).

## Run locally

### Database (PostgreSQL)

```
docker run -d --name janawaz-pg -p 5432:5432 \
  -e POSTGRES_USER=janawaz -e POSTGRES_PASSWORD=janawaz -e POSTGRES_DB=janawaz \
  postgres:16
cp .env.example .env
```

`DATABASE_URL` defaults to `postgresql+psycopg://janawaz:janawaz@localhost:5432/janawaz` (see `.env.example`).

### Backend

```
cd backend
python3 -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
alembic upgrade head
uvicorn app.main:app --reload
# http://127.0.0.1:8000/health
```

### Frontend

```
cd frontend
npm install
npm run dev
# http://localhost:3000
```

## Database migrations

Migrations use Alembic and live in `backend/migrations/`. Run these from `backend/`:

```
alembic upgrade head                          # apply all migrations
alembic downgrade -1                          # roll back the last migration
alembic revision --autogenerate -m "message"  # create a new migration after changing models
```

The initial schema is `0001_initial_foundation`. Always review autogenerated migrations before committing.

## Backend layout

```
backend/
  app/
    core/        # settings and configuration
    db/          # SQLAlchemy base and session handling
    models/      # ORM models: user, contact method, complaint, audit event
    services/    # business logic: complaints, audit logging
  migrations/    # Alembic environment and versions
  tests/         # pytest suite (models, migrations)
```
